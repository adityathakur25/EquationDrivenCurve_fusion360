Equation Driven Curve

Creates a 3D fitted spline in the active sketch from parametric equations of t. Open a sketch, then choose Sketch > Create > Equation Driven Curve.

Dialog

OptionMeaning
Coordinate SystemCartesian, Cylindrical or Spherical. Each system keeps its own equations.
Cartesianx(t), y(t), z(t)
Cylindricalr(t) radius from the sketch Z axis, θ(t) angle from +X in the XY plane, z(t) height.
x = r·cos θ, y = r·sin θ
Sphericalr(t) distance from origin, θ(t) polar angle from +Z, φ(t) azimuth from +X.
x = r·sin θ·cos φ, y = r·sin θ·sin φ, z = r·cos θ
Starting / Ending t valueRange of the parameter t. Ending must be greater than starting. Fusion expressions are allowed (e.g. 2 * PI).
NotificationsNumber of spline control (fit) points that will be created, or the error in your equations.

Coordinates are in the sketch's own coordinate system. Lengths use the document's default length unit (the one shown in the browser's Units node). Angles are in radians. A curve that ends where it starts is made a closed spline.

Expression syntax (muparser compatible)

  • Variable: t. Constants: pi (also _pi), e (also _e). Names are case-sensitive.
  • Operators: + - * /, power ^ (or **), comparisons == != < > <= >=, logic && ||, if-else cond ? a : b.
  • Multiplication must be written: 2*t, not 2t.
